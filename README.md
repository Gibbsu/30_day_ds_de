# 30-Day Data Scientist / Data Engineer Project

This repository tracks my 30-day hands-on study plan for improving my skills in:

- SQL
- Python
- Pandas
- Data Engineering
- Machine Learning
- Git/GitHub

## Project Goal

Build an end-to-end analytics and machine learning project that:

1. Ingests raw data
2. Cleans and transforms data with Python
3. Loads structured data into a SQL database
4. Performs analytical SQL
5. Builds a machine learning model
6. Creates a Power BI dashboard
7. Documents the entire workflow in GitHub

## Project Theme

Supply Chain Sales and Demand Analytics

The project will analyze sales/order data to understand customer demand, product performance, and sales patterns, and eventually build a predictive model using the processed data.
